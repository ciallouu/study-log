# 977. 有序数组的平方

https://leetcode.cn/problems/squares-of-a-sorted-array/

## 思路：对撞双指针

数组有序且有负数，平方后**最大值一定在两端**（绝对值最大），最小值在中间。
因此用两个指针从两端向中间夹，每次取当前最大的平方值，**从结果数组末尾倒着填**。

关键判断：结果数组必须**从后往前填**。从前往后填的话，手上拿到的是"当前最大"，但开头要放"最小"，方向反了填不了。

## 复杂度

- 时间 O(n)：每个元素只看一次
- 空间 O(n)：res 是新数组（这题无法原地，输出本身占 n 位）

## 踩的坑 / 面试点

1. 从前往后填是方向错误（最大值在两端）
2. `l > r` 与 `l >= r` 等价，相等时取哪边都行
3. `int` 乘法：本题 `nums[i] <= 10^4` 平方最多 10^8 安全；若范围到 5 万以上要 `long`（`(long)nums[left] * nums[left]`）
4. Java 增强 for（`for (int x : arr)`）改的是副本，改不了数组元素
5. 若数组无序则不能这么做，只能平方后排序 O(n log n)

## 双指针形态

对撞双指针（两端向中间）——区别于 27 的快慢指针、209 的滑动窗口。
