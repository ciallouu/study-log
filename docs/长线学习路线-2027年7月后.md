## 为什么要单独归档

这份 wiki 质量很高，但它服务的是"想打好系统功底的长期自学者"，是一条 **3-5 年**的路线。
而当前要解决的是"双非本科、零经历、要赶 2027 年 3 月投递季"，是一条 **5 个月**的路线。

两件事不冲突，但**顺序不能反**：先拿到入场券，再用 offer 之后的时间和自信补系统功底。

如果现在按它从 CSAPP 或 CS61A 开始，一年后会有很好的基础，但大概率没有实习、没有能讲的项目 —— 这是这份资源对当前阶段的最大风险。

## 时间成本（估算，含 labs）

| 课程 | 内容 | 时间成本 |
|---|---|---|
| CMU 15-213 (CSAPP) | 计算机系统基础 + 8 个 lab | 120-180h |
| MIT 6.1810 (6.S081) | 在 xv6 上加 11 个内核模块 | 150-250h |
| CMU 15-445 | C++ 实现关系型数据库 | 150-200h |
| Stanford CS144 | 手写 TCP/IP 协议栈 | 80-120h |
| MIT 6.5840 (6.824) | Raft + 分布式 KV | 150-200h |
| MIT 6.031 | 软件构造（Java） | 60-90h |

合计 **> 900 小时**。到 2027 年 3 月的全部可用时间约 660 小时，且要分给算法、八股、项目、投递与面试。

## 唯一例外：现在就可以做的一项

### MIT-Missing-Semester（约 8-10 小时）

讲命令行、Shell 脚本、Git、调试与性能分析、正则。**投入小、回报持续 18 个月**，能直接降低后面装 Docker、配 Nginx、看服务器日志的成本。

只看这 5 讲，其余跳过：
1. 课程概览与 shell
2. 命令行环境
3. Shell 工具与脚本
4. 版本控制（Git）
5. 调试与性能分析

跳过：编辑器配置、LaTeX、安全与密码学、数据整理（按需）。

## 主路线（2027 年 7 月之后）

触发条件：**拿到第一个 offer 之后**开始。

| 顺序 | 课程 | 为什么选它 | 预计 | 简历产出 |
|---|---|---|---|---|
| 1 | **UCB CS186** | 用 **Java** 实现关系型数据库：B+ 树、SQL 并发、故障恢复。和 Java 后端人设绝配 | 120-150h | "用 Java 实现支持 B+ 树索引与并发控制的关系型数据库" |
| 2 | **NJU OS（蒋炎岩，中文）** 或 MIT 6.S081 | 中文课程性价比高；想更硬核再上 6.S081 | 100-200h | "实现用户态线程库/简易内核模块" |
| 3 | **CSAPP 前半 + 3 个 lab** | 补机器级理解。**不用全做**：Data Lab、Bomb Lab、Attack Lab 即可 | 60-80h | "熟悉内存布局、链接、并发与性能分析" |
| 4 | **Stanford CS144** | 手写 TCP 协议栈，把网络八股变理解 | 80-120h | "实现 TCP 协议栈（可靠传输/流量控制/拥塞控制）" |
| 5 | **MIT 6.5840 (6.824)** | Raft + 分布式 KV，后端进阶天花板 | 150-200h | "基于 Raft 实现容错 KV 存储" |

**一句记住**：UCB CS186（Java 版数据库）是最值得投入的一项，它把"索引为什么用 B+ 树"从背诵变成"我写过"。
