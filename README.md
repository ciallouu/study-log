## 目录结构

```
study-log/
├── dsa/          算法题（LeetCode），每题一个文件夹：Solution.java + notes.md
```

## 记录规范

- 每道题 **提交 AC 之后**再入库，`notes.md` 必须写三样：思路、复杂度、踩的坑
- commit message 用这个格式：
  - `feat(dsa): 704 二分查找`
  - `fix(dsa): 修正 27 移除元素的越界判断`
  - `docs: 补充 README 目录结构`
- 跟着视频敲的练习代码、跑不通的代码，**不入库**
