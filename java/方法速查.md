# Java 常用方法速查

> 按"先记规律 → 再记清单"的顺序看。规律比清单重要：**清单会忘，规律能让你猜出没见过的方法。**

---

## 0. 先记命名规律（能猜出 80% 的方法）

| 前缀 / 后缀 | 含义 | 例子 |
|---|---|---|
| `is...` / `has...` / `can...` | 返回 `boolean` 的判断 | `isEmpty()` `hasNext()` `canRead()` |
| `get...` | 取一个值 | `getSize()` `getName()` `get(0)` |
| `set...` | 设置一个值 | `setName()` `set(0, x)` |
| `add` / `put` / `append` | 添加 | `add()` `put()` `append()` |
| `remove` / `delete` / `clear` | 删除 | `remove()` `clear()` |
| `create` / `build` / `of` | 创建 | `List.of()` `Stream.builder()` |
| `to...` | **转换**成另一种类型 | `toString()` `toArray()` `toList()` |
| `as...` | 变成**视图**（不复制） | `Arrays.asList()` |
| `...All` | **批量**操作 | `addAll()` `removeAll()` `containsAll()` |
| `...If` / `...IfPresent` | **带条件**的版本 | `removeIf()` `computeIfAbsent()` |
| `...Index` / `indexOf` | 与**位置/下标**有关 | `indexOf()` `lastIndexOf()` |
| 动词过去分词 | 转换后的结果 | `sorted()` `filtered()` `reversed()` |

**记住这条最有用**：`to` = 转换，`as` = 视图，`...All` = 批量，`...If` = 带条件。

## 1. 集合：List / Set / Collection

| 方法 | 作用 | 示例 |
|---|---|---|
| `add(E e)` | 尾部添加，返回 `boolean` | `list.add(book)` |
| `add(int i, E e)` | 在**下标 i** 处插入，后面元素后移 | `list.add(0, book)` |
| `get(int i)` | 取下标 i 的元素 | `list.get(0)` |
| `set(int i, E e)` | **替换**下标 i 的元素，返回**被替换的旧值** | `list.set(0, newBook)` |
| `remove(int i)` | **删下标 i**，返回被删元素 | `list.remove(0)` |
| `remove(Object o)` | **删对象**（用 `equals` 找），返回 `boolean` | `list.remove(book)` |
| `removeIf(Predicate)` | 按条件批量删除 | `list.removeIf(b -> b.getPrice() > 100)` |
| `size()` | 元素个数 | `list.size()` |
| `isEmpty()` | 是否为空 | `list.isEmpty()` |
| `contains(Object)` | 是否包含（用 `equals`） | `list.contains(book)` |
| `indexOf(Object)` | 第一次出现的下标，没有返回 **-1** | `list.indexOf(book)` |
| `clear()` | 清空全部 | `list.clear()` |
| `addAll(Collection)` | 批量添加 | `list.addAll(other)` |
| `containsAll(Collection)` | 是否包含全部 | `list.containsAll(other)` |
| `toArray()` | 转成数组 | `list.toArray(new Book[0])` |
| `iterator()` | 拿迭代器（遍历时可安全删除） | `Iterator<Book> it = list.iterator()` |
| `subList(int, int)` | 截取**视图**（左闭右开） | `list.subList(0, 3)` |
| `List.of(...)` | 创建**不可变**列表 | `List.of(1, 2, 3)` |

**Set 额外特性**：自动去重；没有 `get(int)`（无序），只有 `add` / `remove` / `contains`。

## 2. Map（键值对）

| 方法 | 作用 |
|---|---|
| `put(K, V)` | 放入，**返回被覆盖的旧值**（新增时返回 `null`） |
| `get(K)` | 取值，不存在返回 **`null`** |
| `getOrDefault(K, V)` | 取值，不存在返回默认值（避免判 null） |
| `remove(K)` | 删除，返回被删的值 |
| `containsKey(K)` | 是否含该键（**最常用**） |
| `containsValue(V)` | 是否含该值（**要遍历，很慢**） |
| `size()` / `isEmpty()` | 大小 / 是否为空 |
| `keySet()` | 所有键（Set） |
| `values()` | 所有值（Collection） |
| `entrySet()` | 所有键值对（**遍历最常用**） |
| `putIfAbsent(K, V)` | 键不存在才放入 |
| `computeIfAbsent(K, f)` | 键不存在则用函数算一个放进去（建缓存/分组常用） |
| `merge(K, V, f)` | 存在则合并，不存在则放入（计数常用） |

遍历写法：

```java
for (Map.Entry<Integer, Book> e : map.entrySet()) {
    System.out.println(e.getKey() + " = " + e.getValue());
}
```

## 3. String（字符串，**不可变**）

| 方法 | 作用 |
|---|---|
| `length()` | 字符个数（**注意：String 是方法，数组是字段 `arr.length`**） |
| `charAt(int i)` | 取下标 i 的字符，返回 `char` |
| `substring(int b)` / `substring(int b, int e)` | 截取（左闭右开） |
| `indexOf(String)` | 第一次出现位置，没有返回 **-1** |
| `lastIndexOf(String)` | 最后一次出现位置 |
| `equals(Object)` | 比较**内容**（`==` 比的是引用！） |
| `equalsIgnoreCase(String)` | 忽略大小写比较 |
| `contains(CharSequence)` | 是否包含子串 |
| `startsWith(String)` / `endsWith(String)` | 前缀 / 后缀 |
| `replace(char, char)` / `replace(CharSequence, CharSequence)` | 普通替换（**字面量**） |
| `replaceAll(String regex, String)` | **正则**替换 |
| `split(String regex)` | 按正则切分，返回 `String[]` |
| `trim()` | 去首尾空白（只认 `<= ' '`） |
| `strip()` | 去首尾空白（**认 Unicode 空白，推荐**） |
| `toUpperCase()` / `toLowerCase()` | 大小写转换 |
| `isEmpty()` | `length() == 0` |
| `isBlank()` | 是否空白（空格也算，**校验常用**） |
| `toCharArray()` | 转成 `char[]` |
| `String.format("%s=%d", a, b)` | 格式化 |
| `String.valueOf(x)` | 任何类型转字符串 |
| `Integer.parseInt(s)` | 字符串转 int（`Double.parseDouble` 同理） |

**不可变的后果**：所有"修改"方法其实**返回新字符串**，原对象不变。

```java
String s = "abc";
s.replace("a", "x");      // ❌ 白写了，返回值被丢弃
s = s.replace("a", "x");  // ✅ 必须接收返回值
```

## 4. StringBuilder（可变，拼接用）

| 方法 | 作用 |
|---|---|
| `append(x)` | 追加（返回自己，可链式） |
| `insert(int i, x)` | 在 i 处插入 |
| `deleteCharAt(int i)` | 删一个字符 |
| `delete(int b, int e)` | 删一段（左闭右开） |
| `replace(int b, int e, String)` | 替换一段 |
| `reverse()` | 反转 |
| `setLength(int)` | 截断/扩展长度 |
| `toString()` | 转成 String |

**规则：循环里拼字符串用 `StringBuilder`，不要用 `+`**（`+` 每次都 new 一个 String，O(n²)）。

## 5. Object 的四个方法（所有类都有）

| 方法 | 默认行为 | 什么时候重写 |
|---|---|---|
| `toString()` | 返回 `类名@哈希码`（无意义） | **几乎总是重写**（打印/调试/日志） |
| `equals(Object)` | 比较**引用**（等价 `==`） | 需要"按内容比较"时 |
| `hashCode()` | 由内存地址算出 | **重写 `equals` 必须同时重写它** |
| `getClass()` | 返回运行时类 | 一般不用重写，`instanceof` 的替代 |

> `equals` 和 `hashCode` 必须成对：`HashMap` / `HashSet` 靠 `hashCode` 定位、靠 `equals` 确认。

## 7. Stream（Java 8+，用到再看）

```java
list.stream()
    .filter(b -> b.getPrice() > 50)   // 过滤
    .map(Book::getTitle)              // 转换
    .sorted()                         // 排序
    .distinct()                       // 去重
    .limit(10)                        // 取前 10
    .collect(Collectors.toList())     // 收集成集合
```

| 方法 | 作用 |
|---|---|
| `filter` | 保留满足条件的 |
| `map` | 一对一转换 |
| `flatMap` | 一对多展开 |
| `sorted` | 排序 |
| `distinct` | 去重 |
| `count` | 计数 |
| `anyMatch` / `allMatch` / `noneMatch` | 是否有/全部/都不满足 |
| `findFirst` | 取第一个（返回 `Optional`） |
| `collect` | 收集结果 |
| `forEach` | 逐个处理（**不要在里改结构**） |

## 8. 最容易搞混的 10 组

| 对比 | 区别 |
|---|---|
| `arr.length` / `str.length()` / `list.size()` | 数组是**字段**、String 是**方法**、集合是 `size()` |
| `list.remove(1)` / `list.remove(Integer.valueOf(1))` | 前者删**下标 1**，后者删**值为 1 的对象** |
| `==` / `equals()` | 前者比**引用/地址**，后者比**内容**；包装类和 String 必须用 `equals` |
| `isEmpty()` / `isBlank()` | 后者认为 `" "` 也是空 |
| `replace` / `replaceAll` | 前者字面量，后者**正则**（`$` `\` 要转义） |
| `Arrays.asList()` / `new ArrayList<>()` | 前者是**视图**，不能 `add`/`remove` |
| `trim()` / `strip()` | `strip` 认 Unicode 空白 |
| `get()` / `getOrDefault()` | 后者避免判 null |
| `Collection` / `Collections` | 前者是**接口**，后者是**工具类**（名字差一个 s） |
| `throw` / `throws` | `throw` 抛异常（语句），`throws` 声明异常（方法签名） |

## 9. 一个通用判断法：看返回值定语义

同一个名字，返回值不同，语义就不同。用 `remove` 举例：

| 写法 | 返回值 | 语义 |
|---|---|---|
| `List.remove(int)` | 被删的**元素** | 按下标删 |
| `List.remove(Object)` | `boolean` | 按对象删 |
| `Map.remove(K)` | 被删的**值** | 按键删 |
| `Iterator.remove()` | `void` | 删当前元素，**遍历时安全** |
| `Collection.removeIf(f)` | `boolean` | 按条件批量删 |

**所以看方法不要只记名字，要看两件事：参数类型 + 返回值类型。** 这两样加起来才是完整签名。
